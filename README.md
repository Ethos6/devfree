**Search and filter it on the website: [ethos6.github.io/devfree](https://ethos6.github.io/devfree/)**

## What makes this list different

- **Every limit is sourced.** Each entry links to the official page where the free tier is stated, and records the date it was last checked.
- **It stays fresh.** A monthly job opens an issue listing entries not re-checked in 6 months, and a weekly job reports broken links.
- **Real free tiers only.** No time-limited trials. Sign-up credits are only listed for the big cloud platforms, and are labelled as such.
- **Structured data.** Everything lives in [`data/*.json`](data), so you can reuse it. Download [`services.json`](https://ethos6.github.io/devfree/api/services.json) directly.
- **Useful filters.** On the website you can filter by category, "no credit card needed" and "open source", and search across names, limits and tags.

## Contributing

Additions and corrections are welcome. Please read [CONTRIBUTING.md](CONTRIBUTING.md) first. In short:

1. Edit the right file in [`data/`](data). Add your entry in alphabetical order.
2. Copy the limits from the provider's pricing page into `free_tier`, set `pricing_url` to that page and `checked` to today's date.
3. Run `npm run format && npm run check`, then open a pull request.

Spotted something outdated? [Report it](https://github.com/Ethos6/devfree/issues/new?template=outdated.yml). It takes a minute.

## Using the data

```bash
curl -s https://ethos6.github.io/devfree/api/services.json | jq '.services[] | select(.category == "databases") | .name'
```

Each service has `id`, `name`, `url`, `pricing_url`, `category`, `description`, `free_tier` (list of limits), `checked` (date) and optionally `credit_card_required`, `notes`, `tags` and `open_source`. The full format is in [`schema.json`](schema.json).
